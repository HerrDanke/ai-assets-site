The CAPA management skill defines problem statement, action planning, and effectiveness check methods for Corrective and Preventive Action.

## When to Use

Load this skill when there is a need to create, review, or manage CAPA (Corrective and Preventive Action).

## CAPA Framework

### Problem Statement

- Define the problem precisely (not symptom description)
- Include: what happened, where it happened, when it happened, scope of impact
- Avoid presupposing causes in the problem statement

### Root Cause Alignment

- Every action must correspond to a confirmed root cause
- Distinguish between Corrective Action (eliminating the root cause of an occurred issue) and Preventive Action (preventing potential issues from occurring)
- Avoid "superficial fixes" — actions must prevent recurrence

### Action Planning

- Every action must include: specific action, responsible person, completion criteria, deadline
- Actions must be verifiable (how to prove the action has been implemented and is effective)

### Effectiveness Check

- Define the criteria and methods for effectiveness checks
- Set the time window for effectiveness checks
- Clarify the criteria for determining "effective"

## Key Compliance Points

- CAPA must form a closed loop with root cause analysis
- Actions must prevent recurrence, not merely restore the status quo
- Effectiveness checks cannot rely solely on "it hasn't happened again" as the only criterion
- Effectiveness confirmation must be completed before CAPA closure

## Writing Rules

- Corrective Action and Preventive Action must be described separately
- Action descriptions must be specific to an executable level (not "strengthen training" or "raise awareness")
- Must include a description of sustainability mechanisms
