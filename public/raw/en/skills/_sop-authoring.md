The SOP authoring skill defines the standard operating procedure writing conventions and structure that comply with GMP requirements.

## When to Use

Load this skill when there is a need to write, review, or optimize SOPs and technical documents.

## SOP Structure

A standard SOP must include the following sections:

1. **Purpose** — One sentence defining what problem the SOP solves
2. **Scope** — Applicable/inapplicable scenarios, personnel, and systems
3. **Responsibilities** — Who does what, using roles rather than personal names
4. **Definitions / Abbreviations** — Definitions and abbreviations
5. **System Description** — System description (if applicable)
6. **Procedure** — Core steps in logical order
7. **Backup / Recovery Requirements** — Backup/recovery requirements
8. **Alarm Handling Requirements** — Alarm handling requirements
9. **Data Integrity Requirements** — Data integrity requirements
10. **Security & Access Control** — Security and access control
11. **Deviations / Exceptions** — Deviation/exception handling
12. **Documentation / Records** — Documentation/record requirements
13. **References** — Reference documents
14. **Appendices** — Appendices

## Key Compliance Points

- All procedures must be executable and traceable
- Emphasize data integrity (ALCOA+)
- Emphasize user permissions and audit trails
- Emphasize segregation of duties and access control
- Include exception handling and escalation mechanisms
- Consider business continuity and disaster recovery

## Writing Rules

- Output in English by default
- Use standard SOP format with proper section numbering
- Concise and unambiguous wording, avoid vague expressions
- Suitable for direct inclusion in controlled document systems
- If the user does not provide complete information, reasonably supplement based on GMP best practices
- Automatically maintain terminology consistency and logical coherence
