# Skill: EN-DE GMP Translation

## When to Use

Load this skill when there is a need to translate GMP technical documents (EN ↔ DE).

## Core Principles

1. **Regulatory Compliance First** — Preserve GMP meaning and regulatory intent
2. **Industry Terminology Consistency** — Use EMA/FDA/ISPE/TÜV standard terminology
3. **Technical Concepts over Literal** — Translate technical concepts rather than word-for-word

## Translation Quality Standard

- German output must resemble documents authored by GMP professionals in Germany/Switzerland/Austria
- English output must resemble documents authored by pharmaceutical quality/validation/engineering professionals
- Avoid colloquial, marketing-style, or machine-translation tone
- Append a **terminology reference table** (at least 5 key terms) after each translation output

## Document Types

Translatable document types:
- SOP / WI / URS / FS / DS / HDS
- IQ/OQ/PQ Protocols & Reports
- Validation Reports / Risk Assessments
- Change Controls / Deviations / CAPA
- Audit Reports / Quality Agreements
